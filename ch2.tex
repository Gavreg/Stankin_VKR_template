\subsubsection{Маркированные и нумерованные списки}

Нумерованный список необходимо использовать тогда, когда важно передать порядок перечеслителей. В остальных случаях используется ненумерованный (маркированный). Примеры в этом разделе не несут смысловой нагрузки и демонстрируют только варианты оформления.

Все списки подчиняются правилам русского языка и являются предложениями. После точки предложение заканчивается, а новое начинается с большой буквы.

Например, включенный в строку нумерованный список может выгладить следующим образом: помидоры бывают разные: 1) чёрные; 2) белые; 3) красные. В этом случае, писать каждый элемент списка с Большой буквы было бы не корректно. Пример этого же списка в выключенном виде: помидоры бывают разные:
\begin{enumerate}[label = \arabic*)]
	\item чёрные; 
	\item белые;
	\item красные.
\end{enumerate}


Когда вам необходимо в пункты списка включать целые предложения, то следует поступать следующим образом. Помидоры  бывают разных видов:

\begin{enumerate}
	\item Помидоры бывают чёрные.
	\item Помидоры бывают белые.
	\item Помидоры бывают красные.
\end{enumerate}


Ненумерованные списки используют если порядок перечисляемых объектов не важен. Пример:

\begin{itemize}
	\item пункт 1;
	\item пункт 2;
	\item пункт 3;
\end{itemize}

\subsubsection{Многоуровневые списки}

Пример списка:
\begin{enumerate}[label = \arabic*)]
	\item чёрные; 
	\item белые;
	\item красные, а именно:
		\begin{enumerate}[label = {\asbuk*)} ]
			\item красно-жёлтые;
			\item красно-белые;
			\item красно-зелёные:
				\begin{itemize}
					\item красно-зелёные в полосочку;
					\item красно-зелёные в клеточку;
				\end{itemize}
		\end{enumerate}
\end{enumerate}

Или так:
\begin{enumerate}[]
	\item Яблоки бывают красные. 
	\item Яблоки бывают жёлтые.
	\item Яблоки бывают красные. Выделяют три типа красных яблок:
	\begin{enumerate}[label*={\arabic*.} ]
		\item Красно-жёлтые яблоки.
		\item Красно-белые яблоки.
		\item Красно-зелёные яблоки.
	\end{enumerate}
\end{enumerate}
